# EDU-Vantage-AI Test Plan

## 1. Objective

Validate the major application workflows and confirm that authentication, academic data submission, ML prediction, dashboards, recommendations, chatbot, RBAC and responsive UI behave as expected.

## 2. Scope

### In Scope
- Registration and login
- Email verification
- Role-based navigation
- Academic performance form
- Input validation
- ML prediction
- Student dashboard
- Teacher/Admin dashboard
- Recommendations and roadmaps
- EduBot
- RBAC
- Theme and responsive layout

### Out of Scope
- Load/stress testing
- Penetration testing
- Production infrastructure security audit

## 3. Test Types

- Functional
- Integration
- Regression
- Negative
- Boundary
- UI/UX
- Responsive
- RBAC/Security
- ML output validation

## 4. Entry Criteria

- Application available
- Test environment accessible
- Required services available
- Test credentials/data available

## 5. Exit Criteria

- Planned test cases executed
- Critical defects verified after fixes
- Regression testing completed
- Test summary documented

## 6. Test Environment

- Desktop browser
- Chrome / Edge
- Application frontend
- Node.js/Express backend
- PostgreSQL
- Python FastAPI ML service

## 7. Deliverables

- Test scenarios
- Test cases
- Defect reports
- Execution report
- Test summary
- Screenshots/evidence
