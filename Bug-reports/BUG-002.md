# BUG-002 — Parent Support Validation Issue

**Severity:** Medium  
**Status:** Verified Fixed

## Description
A validation error occurred for a parent-support value of `0`.

## Root Cause
The validator accepted `0–4`, while the model expected the configured range `1–5`.

## Fix
Validation range was corrected.

## Retest
Boundary values were tested again and the issue was verified fixed.
