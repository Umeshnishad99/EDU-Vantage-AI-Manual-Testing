# BUG-001 — ML Attendance Scaling Issue

**Severity:** High  
**Status:** Verified Fixed

## Description
Garbage GPA predictions were generated when attendance was entered as a percentage.

## Root Cause
The scaler expected attendance in the `0.0–1.0` range while the caller passed `0–100`.

## Fix
Attendance was normalized before model processing.

## Retest
Prediction was re-executed with valid attendance values and the issue was verified fixed.
